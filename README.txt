README — پروژه پیش‌بینی مصرف برق لوازم خانگی
================================================

۱) معرفی پروژه
---------------
هدف پروژه، برآورد/پیش‌بینی مصرف برق لوازم خانگی (Appliances) با استفاده از داده‌های دما، رطوبت،
شرایط محیطی و ویژگی‌های زمانی است. مسئله از نوع Regression و داده‌ها ماهیت سری زمانی دارند.

منبع داده:
UCI Machine Learning Repository — Appliances Energy Prediction — Dataset #374

داده گزارش‌شده:
- 19,735 رکورد
- 31 ستون در نسخه آماده‌شده
- نمونه‌برداری 10 دقیقه‌ای
- حدود 4.5 ماه داده
- Target: Appliances

۳) یافته‌های تحلیلگر
--------------------
- Missing Values گزارش‌شده: صفر
- Duplicate Rows گزارش‌شده: صفر
- ترتیب زمانی بررسی شده است.
- فاصله نمونه‌برداری غالباً 10 دقیقه گزارش شده است.
- ویژگی‌های hour و week_of_day ساخته شده‌اند.
- rv1 و rv2 به‌عنوان متغیرهای تصادفی برای راستی‌آزمایی انتخاب ویژگی حفظ شده‌اند.
- مصرف Appliances دارای توزیع چوله و Peakهای واقعی است.
- ساعت‌های عصر، به‌خصوص حوالی ساعت 18، از دوره‌های پرمصرف گزارش شده‌اند.
- همبستگی خطی ویژگی‌ها با هدف عمدتاً ضعیف است؛ بنابراین مدل غیرخطی باید بررسی شود.
- حذف رکورد صرفاً بر اساس IQR انجام نشده است.

۴) معماری معمار
----------------
تقسیم زمانی:
- حدود 70% Train
- حدود 10% Validation
- حدود 20% Test

Test تا مرحله انتخاب مدل نباید دیده شود.

Baseline:
- پیش‌بینی برابر میانگین Appliances در Train

مدل‌ها:
- Linear Regression
- Ridge
- Random Forest
- Gradient Boosting

Pipeline:
- Imputer داخل Pipeline
- StandardScaler برای مدل‌های خطی
- عدم ورود مستقیم date به مدل

Genetic Algorithm:
- Chromosome دودویی
- Fitness = Validation R² - penalty × feature_ratio
- Tournament Selection
- One-point Crossover
- Mutation
- Elitism
- حداقل یک ویژگی انتخاب می‌شود
- Test نباید در Fitness استفاده شود

ارزیابی:
- R²
- MAE
- RMSE
- Peak MAE
- Normal/Peak analysis
- Actual vs Predicted
